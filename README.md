# 🐾 BritishPaw Auto Facebook Poster

Automatically posts 2 SEO-optimised UK pet content posts per day to your BritishPaw Facebook page.

## Posting Schedule
- 🌅 9:00 AM GMT — Morning post (Mon–Fri)
- 🌆 7:00 PM GMT — Evening post (Mon–Fri)

## Environment Variables (set in Railway)
- `FB_PAGE_ID` — Your BritishPaw Facebook Page ID
- `FB_PAGE_TOKEN` — Your Facebook Page Access Token
- `GROQ_API_KEY` — Your Groq API key (free at console.groq.com)

## Deploy to Railway
1. Upload this folder to GitHub
2. Connect to Railway
3. Set environment variables
4. Deploy!
